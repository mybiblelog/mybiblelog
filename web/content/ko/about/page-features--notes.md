# 노트 페이지

<div class="phone-frame">
  <img alt="My Bible Log 노트 페이지 스크린샷" src="/screenshots/ko/sc10-notes.webp" />
</div>

My Bible Log에서는 성경을 읽으며 떠오른 생각을 자유롭게 적어 두고, 모으고, 정리할 수 있습니다.

노트 페이지에서는 새 노트를 쓰고 이미 써 둔 노트를 다시 손볼 수 있습니다. 시간이 지나면 노트가 제법 쌓이기 마련이라, 잘 정리해 두는 것이 중요합니다.

이때 직접 만든 태그로 노트를 분류하면 편리합니다.

## 노트 쓰기

노트 내용은 형식에 얽매이지 않는 자유 텍스트입니다. 엔터 키로 줄을 바꿀 수 있어서 노트 하나에 여러 문단을 담아도 됩니다.

노트에 인터넷 주소를 적어 두면 저장할 때 My Bible Log가 알아서 링크로 바꿔 줍니다. 나중에 누르기만 하면 그 페이지로 바로 갈 수 있습니다.

노트 하나에 성경 구절을 원하는 만큼 연결할 수 있습니다. 꼭 연결해야 하는 것은 아니라서, 글만 적어 두어도 괜찮습니다.

반대도 됩니다. 구절이 하나라도 연결되어 있다면 본문 없이 노트를 저장할 수 있습니다. 나중에 다시 보거나 메모를 남기고 싶은 구절을 표시해 둘 때 좋습니다.

태그도 선택 사항이며, 노트 하나에 원하는 만큼 붙일 수 있습니다.

## 태그로 걸러 보기

노트 페이지 위쪽의 '태그 필터' 버튼을 누르면 원하는 태그를 골라 그에 맞는 노트만 볼 수 있습니다.

고르는 방식은 세 가지입니다.

* **하나라도 일치** — 고른 태그 중 하나만 붙어 있어도 표시됩니다. 태그를 2개 골랐다면 둘 중 하나만 붙은 노트도, 둘 다 붙은 노트도 모두 나옵니다. 다른 태그가 더 붙어 있어도 상관없습니다.
* **모두 일치** — 고른 태그가 전부 붙어 있어야 표시됩니다. 태그를 2개 골랐다면 하나만 붙은 노트는 빠지고 둘 다 붙은 노트만 남습니다. 여기서도 다른 태그가 더 있어도 괜찮습니다.
* **정확히 일치** — 태그 구성이 정확히 같은 노트만 나옵니다. 고른 태그 중 하나라도 빠지면 제외되고, 고르지 않은 태그가 더 붙어 있어도 제외됩니다.

## 작성 날짜순으로 정렬하기

'정렬' 버튼으로 두 가지 순서를 고를 수 있습니다.

* 최신순
* 오래된순

둘 다 노트를 처음 작성한 날짜와 시각을 기준으로 삼습니다. 나중에 노트를 고쳐도 이 시각은 바뀌지 않습니다.

## 태그로 노트 정리하기

<div class="phone-frame">
  <img alt="My Bible Log 태그 페이지 스크린샷" src="/screenshots/ko/sc11-note-tags.webp" />
</div>

노트 페이지의 '태그' 버튼을 누르면 태그 페이지로 넘어가 직접 만든 태그를 관리할 수 있습니다.

태그마다 색을 정해 두면 한눈에 알아볼 수 있습니다. 나만의 색 규칙을 만들어 노트를 정리해 보세요.

태그에는 설명도 달 수 있습니다. 어떤 용도로 쓰는 태그인지, 어떻게 활용하고 있는지 적어 두면 좋습니다. 여기에 적은 인터넷 주소도 링크로 바뀝니다.

태그 페이지에서는 각 태그가 붙은 노트가 몇 개인지 볼 수 있습니다. 그 숫자를 누르면 노트 페이지로 넘어가면서 해당 태그가 달린 노트만 걸러서 보여 줍니다.

아직 쓰이고 있는 태그는 지울 수 없습니다. 먼저 그 태그가 붙은 노트에서 태그를 떼거나 노트를 지운 다음에 태그를 삭제하세요.
