# 달력 페이지

<div class="phone-frame">
  <img alt="My Bible Log 달력 페이지 스크린샷" src="/screenshots/ko/sc9-calendar.webp" />
</div>

달력 페이지에서는 지금까지의 성경 읽기 기록을 달력 형태로 한눈에 볼 수 있습니다.

날짜를 누르면 그날의 기록이 열립니다. 그 자리에서 기록을 추가할 수도 있어서 빠뜨린 날을 나중에 채워 넣기도 간편합니다.

날짜 칸마다 오늘의 성경 페이지와 같은 진행 표시줄이 있고, 두 가지 파란색으로 채워집니다.

* **진한 파란색**: 그날 새로 읽은 구절 (기준 시작일 이후)
* **어두운 파란색**: 그날 읽은 전체 구절. 읽은 구절이 모두 새 구절이면 어두운 파란색은 진한 파란색 뒤에 완전히 가려집니다.

표시줄이 얼마나 차는지는 일일 구절 목표에 따라 정해집니다. 목표가 86절인데 그날 새 구절을 43절 읽었다면 진한 파란색이 딱 절반까지 찹니다.

구절을 충분히 읽어 일일 구절 목표를 채우면 그 날짜에 진한 파란색 별이 붙습니다. 새 구절을 읽어 목표를 채웠다면 금색 별이 붙습니다.
