# 오늘의 성경 페이지

<div class="phone-frame">
  <img alt="My Bible Log 오늘의 성경 페이지 스크린샷" src="/screenshots/ko/sc4-daily-goal.webp" />
</div>

오늘의 성경 페이지에서는 그날의 성경 읽기 진도를 한눈에 볼 수 있습니다. 맨 위에는 일일 목표까지 얼마나 남았는지 보여주는 진행 표시줄이 있습니다. 목표가 86절이라면 오늘 86절을 읽는 순간 표시줄이 가득 찹니다.

오늘의 기록을 확인하고 정리하는 것도 이 페이지에서 합니다. 고칠 내용이 생겼나요? 기록은 언제든 수정하거나 삭제할 수 있어서, 하루에 여러 번 나눠 읽는 분들께 특히 편리합니다.

진행 표시줄의 색은 다음을 뜻합니다.

* **진한 파란색** — 오늘 처음 읽은 구절
* **어두운 파란색** — 예전에 읽은 적이 있는 구절 (기준 시작일 이후)
* **반짝임 효과** — 새 구절로 일일 목표를 채웠을 때 나타납니다

## 읽기 추천

오늘은 어디를 읽을지 고민되시나요? 오늘의 성경 페이지가 맞춤 구절을 추천해 드립니다. 추천을 따라가면

* 새로운 본문을 만나고
* 일일 목표를 채우고
* 성경 곳곳을 두루 살펴볼 수 있습니다.

추천 본문은 이렇게 골고루 섞여 있습니다.

* 신약성경
* 시편과 지혜서
* 그 밖의 구약성경

추천받은 장을 다 읽으면 곧바로 새로운 장이 올라오기 때문에 늘 새로운 읽을거리가 기다리고 있습니다.
