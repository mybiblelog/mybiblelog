# 어디서나 설치하세요

My Bible Log는 웹사이트인 동시에 '프로그레시브 웹 앱'(PWA)입니다. 그래서 어떤 기기에서든 독립된 앱처럼 설치해 쓸 수 있습니다.

<div style="margin: 1rem">
  <img alt="My Bible Log 데스크톱 앱 스크린샷" src="/screenshots/ko/sc8-install-anywhere.webp" />
</div>

예를 들어 Google Chrome에서는 다음 기기에 PWA를 설치할 수 있습니다.

* Windows
* Mac OS
* Linux
* Android
* iOS

설치하려면 먼저 브라우저에서 My Bible Log를 여세요. Chrome에서 설치하는 방법은 아래 링크에서 확인하실 수 있습니다.

[Chrome에서 PWA 설치하기](https://support.google.com/chrome/answer/9658361)

## 키보드 없이 기록하기

My Bible Log는 모바일에서 쓰기 편하도록 만들었습니다. 많은 분들이 이동 중에 성경을 읽거나, 읽는 자리에 늘 휴대폰을 두고 계시니까요.

타이핑 없이 터치만으로 성경 구절을 고를 수 있어서 스마트폰, 태블릿을 비롯한 터치 기기에서 훨씬 편하게 쓸 수 있습니다.

## 항상 최신 상태로

업데이트도 일반 웹사이트와 똑같습니다.

새로고침 한 번이면 언제나 최신 버전을 쓰실 수 있습니다.
