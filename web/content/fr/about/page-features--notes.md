# Page Notes

<div class="phone-frame">
  <img alt="Capture d'écran de la page Notes de My Bible Log" src="/screenshots/fr/sc10-notes.webp" />
</div>

My Bible Log vous permet de noter librement ce que vous découvrez au fil de vos lectures, pour le rassembler et le mettre en ordre.

Sur la page Notes, vous créez de nouvelles notes et retravaillez celles que vous avez déjà. Comme elles s'accumulent vite, une bonne organisation change tout.

C'est là qu'interviennent vos propres tags, qui vous servent à classer vos notes.

## Créer une note

Le contenu d'une note est du texte libre. Les sauts de ligne (touche Entrée) sont pris en charge : une même note peut donc compter plusieurs paragraphes.

Si vous y écrivez une adresse web, My Bible Log la repère à l'enregistrement et la transforme en lien. Un clic suffit ensuite pour ouvrir la page en question.

Vous pouvez rattacher à une note autant de passages que vous voulez, mais ce n'est pas obligatoire : une note purement textuelle convient très bien.

L'inverse fonctionne aussi : une note sans texte est acceptée dès lors qu'au moins un passage y est rattaché. Pratique pour marquer les passages sur lesquels vous comptez revenir ou écrire plus tard.

Les tags sont eux aussi facultatifs, et une note peut en porter autant que vous le souhaitez.

## Filtrer par tag

Le bouton « Filtrer par tags », en haut de la page Notes, vous laisse sélectionner autant de tags que vous voulez : la liste se réduit alors aux notes correspondantes.

Trois modes de correspondance sont proposés :

* **Tous** - il suffit que la note porte l'un des tags sélectionnés. Avec 2 tags sélectionnés, vous verrez les notes qui ont l'un, l'autre ou les deux. Peu importe qu'elles portent d'autres tags par ailleurs.
* **Tout** - la note doit porter l'ensemble des tags sélectionnés. Avec 2 tags sélectionnés, une note qui n'en a qu'un est écartée, une note qui a les deux est retenue. Là encore, les tags supplémentaires ne gênent pas.
* **Exact** - seules les notes ayant exactement cette combinaison apparaissent. Il suffit qu'un tag sélectionné manque pour que la note soit écartée, et il en va de même si elle porte des tags en trop.

## Trier par date de création

Le bouton « Trier » propose deux possibilités :

* Le plus récent d'abord
* Plus ancien en premier

Les deux se fondent sur la date et l'heure de création initiale de la note. La modifier par la suite ne change pas cet horodatage.

## Créer des tags pour organiser vos notes

<div class="phone-frame">
  <img alt="Capture d'écran de la page Tags de My Bible Log" src="/screenshots/fr/sc11-note-tags.webp" />
</div>

Pour ouvrir la page Tags et gérer les vôtres, cliquez sur le bouton « Tags » depuis la page Notes.

Chaque tag reçoit sa propre couleur pour être reconnu d'un coup d'œil : vous vous constituez ainsi peu à peu votre code couleur personnel.

Vous pouvez aussi donner une description à chaque tag et y préciser à quoi il sert et comment vous l'employez. Les adresses web saisies ici deviennent également des liens.

Sur la page Tags, vous voyez combien de notes utilisent chaque tag. Un clic sur ce nombre vous amène à la page Notes, déjà filtrée pour n'afficher que les notes portant ce tag.

Un tag encore utilisé ne peut pas être supprimé : retirez-le d'abord des notes concernées, ou supprimez ces notes, et vous pourrez ensuite supprimer le tag.
