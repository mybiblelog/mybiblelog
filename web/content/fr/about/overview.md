## Vos retours

Vous pouvez proposer une fonctionnalité, signaler un bug ou nous écrire tout autre message via [ce formulaire](/fr/feedback).

## Contribuer

My Bible Log est un logiciel libre ! Le code source est disponible sur GitHub : [My Bible Log Repository](https://github.com/mybiblelog/mybiblelog)

Chacun est libre de copier le code, de l'adapter à ses besoins, d'héberger sa propre instance de My Bible Log et de contribuer au projet d'origine.
