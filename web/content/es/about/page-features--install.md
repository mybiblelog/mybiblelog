# Instálalo donde quieras

My Bible Log es un sitio web y, al mismo tiempo, una aplicación web progresiva (PWA). Eso significa que puedes instalarlo como una app independiente en cualquier dispositivo.

<div style="margin: 1rem">
  <img alt="Captura de pantalla de la aplicación de escritorio My Bible Log" src="/screenshots/es/sc8-install-anywhere.webp" />
</div>

Con Google Chrome, por ejemplo, puedes instalar una PWA en estos dispositivos:

* Windows
* Mac OS
* Linux
* Android
* iOS

Para instalarla, abre primero el sitio en tu navegador. Aquí están las instrucciones para Chrome:

[Cómo instalar una PWA en Chrome](https://support.google.com/chrome/answer/9658361)

## Registra tu lectura sin teclado

My Bible Log está pensado para usarse cómodamente en el celular, porque muchas personas leen la Biblia mientras viajan o simplemente tienen el teléfono a la mano.

Puedes elegir los pasajes bíblicos sin escribir una sola letra, así que la app se siente natural en celulares, tabletas y cualquier pantalla táctil.

## Siempre al día

Con las actualizaciones, My Bible Log funciona igual que cualquier sitio web.

Solo recarga la página y listo: ya estás usando la última versión.
