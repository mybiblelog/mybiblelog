# Página Notas

<div class="phone-frame">
  <img alt="Captura de pantalla de la página Notas de My Bible Log" src="/screenshots/es/sc10-notes.webp" />
</div>

My Bible Log te deja anotar libremente lo que vas descubriendo mientras lees, para recogerlo y ordenarlo después.

En la página Notas creas notas nuevas y trabajas con las que ya tienes. Como con el tiempo se juntan bastantes, tenerlas ordenadas hace toda la diferencia.

Para eso puedes crear tus propias etiquetas y clasificar las notas con ellas.

## Crear una nota

El contenido de una nota es texto libre. Admite saltos de línea con la tecla Enter, así que una sola nota puede tener varios párrafos.

Si escribes una dirección web dentro de la nota, My Bible Log la reconoce al guardar y la convierte en enlace. Después basta un clic para abrir esa página.

A cada nota puedes conectarle todos los pasajes que quieras, aunque no es obligatorio: una nota de puro texto también sirve.

También funciona al revés: puedes guardar una nota sin texto siempre que tenga al menos un pasaje conectado. Así marcas los pasajes a los que quieres volver o sobre los que piensas escribir más adelante.

Las etiquetas también son opcionales, y una nota puede llevar tantas como quieras.

## Filtrar por etiqueta

Con el botón «Filtrar por etiquetas», arriba en la página Notas, eliges las etiquetas que quieras y la lista se reduce a las notas que coinciden.

Hay tres modos de coincidencia:

* **Cualquiera**: basta con que la nota tenga una de las etiquetas elegidas. Si eliges 2, aparecen las notas que tengan una, la otra o ambas. No importa si además llevan otras etiquetas.
* **Todas**: la nota debe tener todas las etiquetas elegidas. Si eliges 2, las notas con solo una quedan fuera y las que tienen las dos quedan dentro. Tampoco importa si llevan etiquetas adicionales.
* **Exacto**: solo aparecen las notas con esa combinación exacta. Si le falta alguna de las etiquetas elegidas queda fuera, y también queda fuera si tiene etiquetas de más.

## Ordenar por fecha de creación

El botón «Ordenar» te da dos opciones:

* Más reciente primero
* Más antiguo primero

Ambas se basan en la fecha y hora en que creaste la nota originalmente. Editarla después no cambia ese momento.

## Crear etiquetas para ordenar tus notas

<div class="phone-frame">
  <img alt="Captura de pantalla de la página Etiquetas de My Bible Log" src="/screenshots/es/sc11-note-tags.webp" />
</div>

Para llegar a la página Etiquetas y trabajar con las tuyas, haz clic en el botón «Etiquetas» de la página Notas.

Cada etiqueta lleva su propio color para que la reconozcas al instante; poco a poco irás armando tu propio sistema de colores.

A cada etiqueta también puedes ponerle una descripción, con detalles de para qué la usas. Las direcciones web que escribas ahí también se convierten en enlaces.

En la página Etiquetas ves cuántas notas usan cada etiqueta. Al hacer clic en ese número llegas a la página Notas ya filtrada, mostrando solo las notas con esa etiqueta.

No se puede borrar una etiqueta que todavía está en uso: primero quítasela a las notas que la tengan (o bórralas) y después podrás eliminar la etiqueta.
