# Встановлюйте будь-де

My Bible Log - це вебсайт і водночас «прогресивний вебдодаток» (PWA). Тобто його можна встановити як окремий додаток на будь-якому пристрої.

<div style="margin: 1rem">
  <img alt="Скріншот додатка My Bible Log на комп'ютері" src="/screenshots/uk/sc8-install-anywhere.webp" />
</div>

Наприклад, за допомогою Google Chrome PWA можна встановити на таких пристроях:

* Windows
* Mac OS
* Linux
* Android
* iOS

Щоб встановити додаток, спершу відкрийте сайт у браузері. Інструкція для Chrome доступна тут:

[Як встановити PWA в Chrome](https://support.google.com/chrome/answer/9658361)

## Введення без клавіатури

My Bible Log зроблено зручним для телефона, адже багато хто читає Біблію в дорозі або просто тримає телефон під рукою.

Уривки Біблії ви обираєте кількома дотиками, без набору тексту, - тож користуватися додатком на смартфоні, планшеті чи іншому сенсорному екрані значно приємніше.

## Завжди актуальна версія

З оновленнями My Bible Log поводиться як звичайний вебсайт.

Просто оновіть сторінку - і ви вже працюєте в найновішій версії.
