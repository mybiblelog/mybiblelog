# Як користуватися ШІ-агентом з My Bible Log

Усе, що можна зробити в My Bible Log, доступне через його відкритий API. Тож ШІ-агент або скрипт, який агент допоможе вам написати, може записувати ваше читання, робити нотатки й керувати тегами замість вас.

На цій сторінці зібрано ті кілька фактів, які потрібні агентові для початку. Дайте йому цю сторінку та довідник API, наведений нижче.

## Довідник API

* **Специфікація OpenAPI (JSON):** [mybiblelog.com/api/openapi.json](https://www.mybiblelog.com/api/openapi.json)
* **Базова URL-адреса:** `https://www.mybiblelog.com/api`

Більшість агентів можуть прочитати специфікацію OpenAPI безпосередньо й дізнатися з неї про кожну кінцеву точку.

## Знайомі посилання на уривки

Уривки записуються короткими посиланнями у форматі, який використовують YouVersion і Bible.com, тож агентові ніколи не доводиться працювати з внутрішніми номерами віршів My Bible Log:

| Уривок | Посилання |
| --- | --- |
| Буття | `GEN` |
| Псалом 23 | `PSA.23` |
| Буття 1–3 | `GEN.1-3` |
| Іван 3:16–18 | `JHN.3.16-18` |
| Буття 1:1 – 2:3 | `GEN.1.1-2.3` |

Уривок не виходить за межі однієї книги. Номери розділів і віршів відповідають англійським Бібліям, як-от NASB, тому в книзі Малахії 4 розділи.

Відповіді містять те саме посилання в полі `passage` поряд із внутрішніми номерами віршів.

## Вхід

Кожен запит потребує токена входу, який надсилається в заголовку:

```
Authorization: Bearer <token>
```

Отримайте токен, увійшовши за допомогою електронної пошти й пароля:

```bash
curl -X POST https://www.mybiblelog.com/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com", "password": "your-password"}'
```

Токен міститься у відповіді в полі `data.token` і діє 30 днів.

* **Реєструвалися через Google?** Спершу створіть пароль у розділі **Налаштування → Змінити електронну пошту**.
* **Нікому не повідомляйте свій пароль.** Увійдіть самі й дайте агентові лише токен.
* **Бережіть токен, як пароль.** Він дає повний доступ до вашого облікового запису, зокрема до його видалення.
* **Щоб відкликати токен,** скористайтеся кнопкою **Вийти з усіх сеансів** у налаштуваннях або змініть пароль.

## Типові завдання

| Завдання | Запит | Тіло |
| --- | --- | --- |
| Записати читання | `POST /log-entries` | `{"date": "2026-11-11", "passage": "JHN.3"}` |
| Переглянути записи читання | `GET /log-entries` | |
| Створити нотатку | `POST /passage-notes` | `{"content": "…", "passages": ["JHN.3.16-18"], "tags": ["<tag id>"]}` |
| Знайти нотатки до уривка | `GET /passage-notes?filterPassage=JHN.3` | |
| Створити тег | `POST /passage-note-tags` | `{"label": "Молитва", "color": "#3a7bd5"}` |
| Переглянути теги | `GET /passage-note-tags` | |
| Прочитати налаштування | `GET /settings` | |

Дати записуються у форматі `YYYY-MM-DD` за вашим часовим поясом. Наприклад, щоб записати Івана 3 як прочитане сьогодні:

```bash
curl -X POST https://www.mybiblelog.com/api/log-entries \
  -H "Authorization: Bearer $MBL_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"date": "2026-11-11", "passage": "JHN.3"}'
```

## Поради для агентів

* **Помилки перевірки конкретні.** Відповідь `400` перелічує кожне поле з помилкою та її причину, тож агент може виправити запит і повторити його.
* **Зробіть резервну копію перед масовими змінами.** Завантажте свої дані в розділі **Налаштування → Експорт**, перш ніж дозволити агентові редагувати чи видаляти багато записів одразу.
* **Кількість входів обмежена.** Використовуйте один токен повторно, а не входьте для кожного запиту.
